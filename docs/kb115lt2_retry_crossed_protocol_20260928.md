# Prepared fixed-shop retry comparison

This experiment is prepared but has not run. It isolates V12's bounded partial-WHEAT-pickup retry on two already observed mechanism cases, live01 and live07. These are deliberately selected development examples, not a new random validation panel. It cannot replace the native V8/V12 outcomes or qualification results.

The design contains eight fresh games: each case crossed with its own V8-natural and V12-natural shop sequences, with retry OFF and ON in each context. Both arms use the same optimized V12 executor, source closure, semantic model, opening, financing and live responsive frozen MGT V9lite opponent. Their only file difference is the `sd_tier_wheat_retry` bit in the candidate configuration. This avoids comparing the slower original V8 execution against the optimized V12 code. No native diagonal is reused, because exact source and action equivalence has not been established; post-run native reproduction remains a separate diagnostic.

The full shop sequence is available only to the harness, which applies each day's revealed shops through the existing frozen engine wrapper. Both agents receive ordinary current official observations and configuration. They receive no source recording, future shop schedule, experiment identity or future semantic plan. Weeds remain natural. Read-only hooks hash pre-call observations with only the runtime bank removed and save post-call retry events. The report requires both action streams and both observed-state streams to match before the first accepted ON retry; a failure is retained explicitly rather than interpreted as a clean component effect.

Each game uses a fresh process, one engine worker, the normal one-second action limit and 60-second overage bank, and at least 3.3 GiB available RAM. Dispatch stops on a technical, ledger, opponent-health or runtime failure, retaining the attempt and planned denominator. There is no win-count stop or six-win promotion condition for this comparison. No qualification games are scheduled.

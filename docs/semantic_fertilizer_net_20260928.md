# Optional fertilizer net-flow correction

The policy previously treated animal fertilizer output as market supply while omitting both farms' internal crop use. The default-OFF `forecast_fertilizer_net` option subtracts an engine-timed input calendar, credits our observed shed/carried stock once, and distinguishes gross harvest history from signed market trades. New crop input costs use the same calendar. Current observations supply fertilizer expiry and yield; replacements cannot inherit a predecessor's effect.

# Plan vs jitter: how divergent can top agents' plans get on the same seed (days 7-29)?

Generated by `scripts/analyze_plan_vs_jitter.py`. No games simulated; all numbers parsed from recorded replay/tape JSON. Board distance = L1 over 8 counts (5 crop tile counts + 3 animal counts); cash and quadrant differences are reported separately. k(d) = min(8, d//3) shop-reveal-prefix length; matched-pair cells fall back to a smaller k when fewer than 5 matched pairs exist at the target k (noted per cell). Unmatched pairs are random pairs (same agent) whose prefix differs at the k actually used.

## Caveats (apply throughout)

- Opponents differ between games (except DSM self-play and any noted same-seed pair), so final-cash spread mixes plan variance with opponent variance.
- UMG-old cow counts are an upper bound (the compact board encoding collides an occupied cow pasture with an empty coop, code 'co'); sheep/goose/crops are exact.
- Board state for DECEM and Vadim Vasilenko comes from downloaded full replays (exact tiles); board state for 'M & M & P & Q' and 'Boey' was NOT downloaded for this analysis (out of the required scope) -- only their seed/action-divergence/same-seed results are reported. 'Unknown Mother-Goose (current)' board data is downloaded only if the leader-full-optional stage was run before this report; check n_with_board_data.
- Weeds and the exact opponent farm depend on the seed and the opponent, not on shops alone, so even a perfectly matched shop-prefix pair are not literally the same world.
- Small-n cells (n<5) are anecdotal; every table reports n.
